# ClassCheck V10.2 — Login and Install Flow

ClassCheck now separates the normal website entry from the installed PWA experience.

## Normal mobile/desktop browser
1. Open the ClassCheck link.
2. The login/install screen stays visible.
3. Install ClassCheck before or after signing in.
4. If the browser already has a valid session, choose **Continue to ClassCheck** or **Log out**.

## Installed ClassCheck PWA
1. Tap the ClassCheck app icon.
2. If the previous session is still valid, ClassCheck restores it and opens the workspace.
3. If there is no valid session, the login screen appears.

## Log out
Open **Profile** from the mobile bottom navigation, then tap **Log out**. The session is cleared and ClassCheck returns to the login screen.

No SQL update is required.
