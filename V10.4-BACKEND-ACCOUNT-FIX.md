# ClassCheck V10.4 — Backend / Account Fix

This build fixes the ClassCheck account-creation/login error.

## What was wrong
The V10.3 frontend was still pointed at the older MathHub Supabase project. That project contains Mathside-side authentication/database behavior, so creating a ClassCheck teacher account could fail with a Supabase user/database error.

## What changed
- ClassCheck now points to its dedicated Supabase project: `rvzuqzgktdcyzyayftks`.
- The dedicated ClassCheck database schema, RLS policies, class-sharing RPCs, attendance tables, and SF2 baseline fields were installed directly in that project.
- The PWA cache was bumped to V10.4 so mobile browsers do not keep the old backend configuration.
- V10.3 dynamic SF2 behavior is retained.
- V10.2 login/install behavior is retained.

## What you need to do
1. Upload this V10.4 build (or the update files) to the ClassCheck GitHub Pages repository.
2. Close old ClassCheck tabs on your phone.
3. Reopen the website and refresh once.
4. Choose **Create account** and create your ClassCheck teacher account.
5. If email confirmation is enabled, confirm the email, then sign in.

No SQL needs to be run manually for this fix; the dedicated ClassCheck Supabase backend has already been configured.
