# ClassCheck V10.3 — Dynamic SF2

The original SF2 workbook remains the visual master. ClassCheck now expands the learner section when the selected class is larger than the built-in template capacity.

## Dynamic behavior

- Male learners start at the original male section. Extra male learner rows are inserted before the Male Total row when needed.
- Female learners follow the Male Total row. Extra female learner rows are inserted before the Female Total row when needed.
- Male Total, Female Total, Combined Total, summary computations, adviser name, and school-head name are moved automatically to the correct rows.
- Inserted rows copy the exact learner-row styles and merged-cell pattern from the original SF2 template.
- Different class/section names and different roster sizes are supported.
- The generated filename continues to use the selected grade, section, and month.

No new SQL is required.
