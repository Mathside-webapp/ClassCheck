# ClassCheck V10.5 — workflow verification

- Dedicated ClassCheck Supabase project only.
- Create class now uses a secure RPC to avoid browser-side RLS insert failures.
- Add/import/delete learners use adviser-checked RPCs.
- Join class uses the six-character class code.
- Subject teachers can leave a joined class.
- Advisers can archive and later restore/unarchive a class without deleting attendance.
- Attendance sync uses one authenticated RPC while keeping the existing offline queue.
- SF2 baseline saving uses an adviser-checked RPC.
- Dynamic SF2 and regular Excel exports remain client-side downloads.
- Permanent class deletion remains available to the adviser.
