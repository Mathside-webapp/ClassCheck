# ClassCheck V10.7 — Editable Students

- Manual Add Learner now includes an optional LRN field.
- LRN can be left blank and added later.
- Class advisers can edit Last Name, First Name, Middle Name, Sex, and LRN.
- Entered LRNs must be exactly 12 digits and must be unique within the class.
- Editing keeps the same learner ID, so existing attendance records remain linked.
- SF1 import remains unchanged and continues to preserve imported LRNs.
- Backend RPC `classcheck_update_student` was added with adviser-only authorization.
